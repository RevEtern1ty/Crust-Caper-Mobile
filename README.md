# CrustCaper Mobile

Приложение для гостевого предзаказа и самовывоза в Кигали. Клиент открывает меню, собирает корзину, подтверждает окно выдачи и отслеживает текущий заказ. Доступны английский и киньяруанда.

## Запуск

Установите Node.js 24 и запустите команды из корня репозитория.

```sh
npm ci
npm run web
```

В браузере доступен локальный сценарий с синтетическим меню, заказом и оплатой. При оформлении выберите «Use demo number». На экране оплаты можно проверить подтверждение, отказ и ожидание. В разделе Orders можно проверить подготовку заказа, код выдачи и повтор. Для запуска Metro с установленной development build выполните `npm start`.

Для development build на Android требуется Android SDK и эмулятор или устройство. Для iOS нужен macOS с Xcode и симулятор или устройство. Из корня запустите соответственно `npm run android` или `npm run ios`.

## Проверки

```sh
npm run check
npm run build:web
npm run test:web
npm run build:android
npm run build:ios
```

`npm run check` запускает линт, проверку типов и тесты. Для `npm run test:web` нужен Google Chrome. В `dist/` будет статическое превью, в `dist-android/` и `dist-ios/` — JS-пакеты для соответствующих платформ. CI сканирует историю и npm-зависимости и формирует SBOM. На `main` CI также собирает Android APK с демо-данными и отладочной подписью для ARM64 и x86-64.
