# Восстановление доступа к заказу по телефону

На другом устройстве клиент вводит идентификатор заказа и телефон, указанный при покупке. Код по SMS подтверждает наличие доступа к телефону для этого заказа. Храните и передавайте код только на время проверки. Провайдер возвращает внутренний идентификатор проверки `VE…`, который сервер использует при подтверждении.

Если гостевая сессия истекла, экран Orders предлагает подтвердить сохранённый заказ по телефону и подставляет его короткий номер. До подтверждения отдельная сессия используется только для проверки телефона. Неопределённые операции оформления и оплаты сохраняют прежнюю привязку. Статус и чек восстановленного заказа можно открыть, а платёжные действия остаются у исходной сессии. Если сохранённый заказ подтверждён сервером и текущая операция завершена, покупатель может оформить новый заказ.

## Конфигурация Twilio Verify

Восстановление по телефону по умолчанию отключено. Для подключения стенда задайте `CRUSTCAPER_ORDER_ACCESS_PROVIDER=twilio` и следующие переменные в серверном хранилище секретов. Для отключения уберите переменную провайдера или задайте `disabled`.

| Переменная | Значение |
| --- | --- |
| `CRUSTCAPER_TWILIO_VERIFY_SERVICE_SID` | SID выделенного Verify Service, начинается с `VA`. Используйте отдельный сервис для каждой среды. |
| `CRUSTCAPER_TWILIO_VERIFY_API_KEY_SID` | SID ключа API (`SK…`) с правами запуска проверки и проверки кода в Verify. |
| `CRUSTCAPER_TWILIO_VERIFY_API_KEY_SECRET` | Секрет того же ключа. |

Настройте шестизначный код в Verify Service. Разрешите SMS для утверждённых стран, включите защиту от SMS-фрода и настройте лимиты и мониторинг расходов до подключения реальных телефонов. Для проверки доставки используйте отдельный стенд и согласованный тестовый номер. Twilio работает по HTTPS и использует HTTP Basic authentication с ключом и секретом. [Настройка сервиса](https://www.twilio.com/docs/verify/api/service) · [Аутентификация Verify](https://www.twilio.com/docs/verify/api) · [Защита от фрода](https://www.twilio.com/docs/verify/preventing-toll-fraud) · [Географические разрешения](https://www.twilio.com/docs/verify/preventing-toll-fraud/verify-geo-permissions)

Транспорт отправляет телефон в формате E.164 только при запуске SMS. При проверке передаёт `VerificationSid` и код. Доступ подтверждается только после статуса `approved` из нужного Verify Service для того же SID и канала `sms`. Twilio может повторно отправить тот же код в пределах срока действия. Сервер обрабатывает завершённую, исчерпанную или отсутствующую проверку как недействующую. [Запуск проверки](https://www.twilio.com/docs/verify/api/verification) · [Проверка кода](https://www.twilio.com/docs/verify/api/verification-check) · [Срок действия кода](https://www.twilio.com/docs/verify/api/rate-limits-and-timeouts)

При неизвестном результате запроса к Twilio сервер сохраняет существующие права. Если сервер успел записать подтверждение, то повтор запроса от той же гостевой сессии вернёт сохранённый номер заказа. Если подтверждение провайдера потерялось до записи доступа, пользователь запрашивает новый код после периода ограничения. Телефон, код, ключи, полный ответ провайдера и идентификаторы проверок исключаются из клиентских ответов и диагностики.

API создаёт временную заявку и проверяет совпадение номера с заказом в фоновой очереди. Ответ о получении заявки одинаков для совпавшего и незнакомого заказа. В заявке хранится ограниченный по времени отпечаток введённого телефона. Отправка ограничена по гостевой сессии, телефону и размеру очереди. Доступ относится только к выбранному заказу. На другом устройстве можно смотреть состояние и повторить покупку новой корзиной. Исходная оплата и сессия заказа сохраняют исходного владельца.

## Локальная проверка

При `SPRING_PROFILES_ACTIVE=local` и `CRUSTCAPER_ORDER_ACCESS_PROVIDER=local` используется синтетическая проверка для номера `+250700000000` и кода `418263`. Она не отправляет сообщения, допускает только этот номер и хранит короткоживущие одноразовые проверки в памяти процесса. Профили `stage`, `prod` и `production` отклоняют локальный провайдер. Профиль `local` отклоняет Twilio.

`./gradlew test --tests 'com.crustcaper.api.recovery.*'` из `server/` проверяет настройки транспорта и запросы на loopback-стенде. `npm run test:connected` проходит восстановление из новой браузерной сессии на локальном API. Перед подключённым выпуском отдельно подтвердите доставку и успешное восстановление, неверный код, истечение срока, потерю подтверждения и ограничения повторов. Используйте реальные SMS только в согласованной среде.
