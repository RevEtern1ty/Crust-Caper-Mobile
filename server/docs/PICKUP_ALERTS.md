# Уведомления о готовности заказа

Гость может включить уведомление о готовности оплаченного заказа в разделе Orders, пока заказ принят или готовится и его окно выдачи ещё не закончилось. Разрешение ОС запрашивается по нажатию на кнопку. Согласие действует для одного заказа и одной установки. Статус заказа доступен в приложении при любом выборе. Доступ к настройке имеют исходная гостевая сессия и сессия, восстановившая именно этот заказ после подтверждения телефона.

## Настройка стенда

По умолчанию отправка выключена. Для подключения используйте подписанные нативные сборки, проект Expo с Firebase Cloud Messaging для Android и APNs для iOS. Включите Enhanced Push Security. Для стенда и production используйте отдельные проекты с собственными ключами и данными. [Настройка push в Expo](https://docs.expo.dev/push-notifications/push-notifications-setup/) · [Защита Expo Push Service](https://docs.expo.dev/push-notifications/sending-notifications/#additional-security)

При выключенной отправке сервер возвращает `available: false`. Приложение убирает кнопку включения и сохраняет возможность отозвать записанное согласие. Отслеживание заказа через API остаётся доступным.

| Параметр | Где задаётся | Назначение |
| --- | --- | --- |
| `CRUSTCAPER_PUSH_PROJECT_ID` | Нативная сборка `stage` или `production` | Публичный UUID проекта EAS, используемый клиентом при получении Expo-токена. |
| `CRUSTCAPER_ANDROID_GOOGLE_SERVICES_FILE` | Нативная сборка Android | Путь к `google-services.json` для пакета этой среды. В EAS можно передать файловой переменной. |
| `CRUSTCAPER_PUSH_PROVIDER=expo` | Сервер | Включает регистрацию согласия и доставку. |
| `CRUSTCAPER_PUSH_TOKEN_KEY` | Серверный менеджер секретов | Уникальный случайный ключ из 32 байт в Base64 для шифрования хранимых токенов. Экземпляры сервера одной среды используют один ключ. |
| `CRUSTCAPER_EXPO_PUSH_ACCESS_TOKEN` | Серверный менеджер секретов | Access Token для защищённых запросов к Expo Push Service. |

При замене ключа шифрования дождитесь обработки активных записей или отзовите их с очисткой токенов до переключения всех экземпляров. При использовании реплик все экземпляры должны читать одну базу и использовать одну конфигурацию провайдера.

## Доставка

Сервер ставит запись в очередь в той же транзакции, в которой оператор переводит заказ в `ready`. Запись проверяется перед отправкой. Её срок истекает при завершении окна выдачи, истечении гостевой сессии или через 30 минут после постановки в очередь, в зависимости от того, что наступит раньше. Отзыв очищает токен и останавливает ожидающую отправку. Expo может доставить сообщение, которое уже принял до отзыва или выдачи заказа.

Сообщение содержит короткий текст о готовности и служебный идентификатор заказа для навигации. Данные телефона, оплаты, состава заказа и код выдачи отсутствуют в сообщении. При открытии приложение использует только заказ, известный текущей сессии, и заново запрашивает статус через авторизованный API.

При неопределённом результате отправки сервер не дублирует её. После подтверждения отправки Expo возвращает ticket для сверки. Сервер проверяет receipt, начиная через 15 минут, и прекращает сверку через 24 часа с постановки в очередь. После завершения обработки токен удаляется. Служебная запись удаляется через 24 часа после завершения. Подтверждение Expo относится к передаче Apple или Google. Проверку получения и нажатия проводят на телефоне. [Tickets и receipts Expo](https://docs.expo.dev/push-notifications/sending-notifications/#check-push-receipts-for-errors)

## Приёмка

- На Android и iOS оформите оплаченный тестовый заказ, включите уведомление и закройте приложение. Переведите заказ в «Готов». Проверьте уведомление, его безопасное содержимое и переход к заказу после нажатия.
- Проверьте отказ ОС в разрешении, выключение до перехода в «Готов», отсутствие сообщения до готовности, повтор команды кухни и попытку доступа к чужому заказу. Приложение продолжает показывать статус через API.
- Сверьте очередь и receipts в пределах тестового окна. Утвердите тексты на EN и RW, срок хранения и обработку данных Expo до работы с реальными покупателями.
